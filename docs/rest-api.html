REST API

A FastAPI server for any non-MCP client. Included out of the box — fastapi, uvicorn, pydantic, and sse-starlette are core dependencies. No extra install flags.

On this page

Start the server

Binds to http://127.0.0.1:8912 by default. Ports come from server.mcp_port / server.rest_port in config.

# foreground
memorius serve-rest

# background daemon
memorius serve-rest --daemon

# stop the daemon
memorius serve-rest --stop

Flags: --port, --host (default 127.0.0.1), --daemon, --stop, --pid-file, and --tls-cert / --tls-key (PEM) for HTTPS.
