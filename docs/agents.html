Detection priority

When multiple markers could match, the most-specific wins. Order is fixed:

OpenClaude → Claude Code → Codex → Gemini CLI → OpenClaw → OpenCode → Pi → Generic

You can override auto-detection with --agent <name> on any memorius-hook command.

Three ways to integrate

MethodBest forHow
MCP server Any MCP-compatible agent (Claude Code, Codex, Gemini, Cursor, Aider…) Point the agent at memorius serve. See MCP Server.
Agent hooks Auto-capture at session boundaries Generate per-agent hook scripts with memorius-plugin-gen. See Hooks.
Agent skill Hermes-compatible agents that should use memorius proactively One npx command. See Install the skill.

Plug in your own agent

Memorius is agent-agnostic by design. Two paths for a custom agent:

  1. Generic hook adapter. Pipe your agent's event JSON to memorius-hook. The Generic fallback handles any unrecognized payload — no marker needed.
  2. A new marker. Add a recognition rule to the hook engine's detection table so your agent gets its own adapter (events, actions) instead of the generic path.
No MCP support in your agent?
Use the REST API directly — any HTTP client can store and search memories against the same vault.
