MCP server

MCP is the primary interface for AI agents. Connect any MCP-compatible client by pointing it at memorius serve — JSON-RPC over stdio, no port, no auth. 29 tools.

On this page

Connect an MCP client

Run the server, then register it in your client's MCP config.

memorius serve

Generic MCP client config (Claude Code, Codex, Gemini all use a similar shape):

{
  "mcpServers": {
    "memorius": {
      "command": "memorius",
      "args": ["serve"]
    }
  }
}

The tools surface immediately. Each tool returns a JSON result that your agent can read without a custom SDK.

Memory tools

Store, read, update, and search memories in the vault hierarchy.

ToolWhat it does
memorius_storeStore content in a vault/shelf/folder/note path; supports ttl_days.
memorius_searchSemantic search with expand_graph, rerank, tags, and cursor pagination.
memorius_getFetch one memory by UUID, including full content + metadata.
memorius_updateUpdate content/metadata; re-embeds when content changes.
memorius_deleteDelete a memory by ID from both vector and metadata stores.
memorius_listList memories with cursor pagination (newest first).
memorius_vault_lsBrowse the vault hierarchy — vaults, shelves, folders, notes.
memorius_contextFormatted memory block for injection into agent context.
memorius_contradictionsMemories that contradict a given memory (knowledge-graph contradicts edges).

Learning tools

Agent self-improvement loop — capture a learning, recall it later, track how often it's applied.

ToolWhat it does
memorius_learnStore a learning — bug fix, strategy, pattern, tool tip, snippet, or workflow.
memorius_recallSearch past learnings by category/tag.
memorius_learningsList all learnings with application counts and summary.
memorius_apply_learningMark a learning as applied (increments its counter).
memorius_learning_statsLearning statistics — counts, categories, application rates, confidence.
