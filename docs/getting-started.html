Up and running in 30 seconds

Install, initialize, store, search. No cloud account, no API keys, no setup ceremony.

Step 1 Install

One command. All features — vector search, reranker, REST API, knowledge graph, and the agent skill — are included out of the box.

pip install memorius
Verify the install
Run memorius --version to confirm the CLI is on your PATH, then memorius init to create ~/.memorius/config.yaml and the storage directory.

For development (adds pytest + pytest-asyncio):

pip install "memorius[dev]"

Step 2 Initialize a vault

Creates the config file and storage. Runs the ONNX model download on first use.

memorius init

If you want to pre-download the bundled ONNX embedding model now (instead of on first search):

memorius setup

The vault engine lives under ~/.memorius/data by default. You can override every setting via the MEMORIUS_* environment variables or the YAML config — see Architecture → Configuration.

Step 3 Store your first memory

Content is embedded automatically and placed in the hierarchy you name.

memorius store "The sky is blue because Rayleigh scattering scatters shorter wavelengths more" \
  --vault main --shelf science --folder physics

Flags: --vault / --shelf / --folder / --note name the four levels of the hierarchy (all default to main / default). --ttl 30 sets a time-to-live in days.

Step 4 Find it later with semantic search

Relevance-ranked results from the vector store — you don't need the exact words.

memorius search "why is the sky blue"

Useful flags: --n 20 (more results), --expand-graph (pull in 1-hop linked memories), --rerank (cross-encoder precision), --web (fallback to live web when local recall is thin). Full flag reference is on the CLI page.

The Vault → Shelf → Folder → Note hierarchy

Four levels of organization, so a single vault can hold everything from one project to an entire research corpus.

LevelWhat it holdsExample
VaultA top-level namespace. One per project/domain.main, conversations, research
ShelfA category or theme within a vault.science, decisions, bugs
FolderA sub-grouping within a shelf.physics, auth
NoteThe individual memory itself.rayleigh-scattering

Browse the live structure at any time:

memorius ls

Diaries, mined transcripts, and extracted memories each land in their own shelves, so your vault stays organized without manual filing.

Install the agent skill

Memorius ships a pre-built agent skill. One command installs it into your agent's skill directory — no cloning, no build step.

npx skills add github.com/Dream-Pixels-Forge/memorius/tree/main/skills/memorius

The skill teaches any Hermes-compatible agent to use memorius proactively: auto-capture rules, smart context injection, session diaries, and workflow templates. For agents without the skill format, use the MCP server or the CLI directly.

Recommended first-week flow

  1. Day 1 — memorius init, store a handful of decisions, search for them. Feel the hierarchy.
  2. Day 2 — Mine a real transcript: memorius mine transcript.txt --vault conversations.
  3. Day 3 — Wire your agent: add the MCP server to Claude Code / Codex / Gemini, or hook it up so memories capture automatically at session boundaries.
  4. Ongoing — Run memorius doctor after big sessions, and memorius consolidate to merge duplicates as the vault grows.
